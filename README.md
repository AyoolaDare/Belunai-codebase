# BELUNAI

A mobile-first Christian-values social network, starting in Nigeria.

- Specification (v2.1): [`docs/`](docs/) — PRD, engineering rules, backend schema, implementation plan
- Progress: [`docs/implementation_status.md`](docs/implementation_status.md)
- Setup and commands: [`docs/development.md`](docs/development.md)

## Quick start

Requires Node.js 22 and npm.

```bash
npm ci
npm run dev
```

Full local check (what CI runs before E2E):

```bash
npm run check
```
